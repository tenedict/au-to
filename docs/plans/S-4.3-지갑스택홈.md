# S-4.3 · 지갑 스타일 마감 스택 홈

> `bmad`/Superpowers `writing-plans` 대응. 2~5분짜리 태스크로 쪼갠 실물.
> 완료 2026-08-01

---

## 요구

> "메인화면에는 마감일이 다다른 것부터 애플 스타일로 쫙 보여주고, 애플 기본앱 지갑 느낌으로
> 오늘 마감인 거 그리고 마감일 넘은 것들 마감 가까운 순으로 정렬되어 있고,
> 오늘 마감인 거 누르면 쭉 펼쳐지고 스크롤해서 다음 마감인 거 누르면 뚝 펼쳐지고"

---

## 되물어서 갈린 결정

| 질문 | 결정 | 왜 |
| --- | --- | --- |
| 마감 지난 것과 오늘 것 중 뭐가 위인가? | **지난 마감이 위** | 이미 늦은 것이 제일 급하다 |
| 지난 마감 안에서는? | **가장 오래 밀린 것이 위** | 3일 지난 것이 1일 지난 것보다 급하다 |
| "이번 주"는 언제까지인가? | **앞으로 7일** (이름도 그대로) | 일요일에 "이번 주"는 오늘 하루로 읽힌다 |
| 여러 개를 동시에 펼칠 수 있나? | **하나만** | 여럿이 펼쳐지면 "지금 뭘 보고 있는지"가 사라진다 |
| 완료한 할 일도 스택에 있나? | **별도 묶음, 접힌 채로** | 끝낸 일이 급해 보이면 목록 전체를 안 믿게 된다 |
| 오늘 오후 2시 예약을 오후 6시에 보면? | **지난 마감** | 날짜만 비교하면 이미 늦은 걸 오늘 할 일로 보여준다 |
| 종일 할 일은 저녁에도 오늘인가? | **그렇다** | 시각이 없으므로 지날 시각도 없다 |

## 태스크

### 1. `DueBucket` 열거형 (2분)

- 파일 — `CaptureTask/Models/DueGrouping.swift` (새 파일)
- `overdue / today / within7Days / later / someday / done`
- `title` · `symbolName` · `startsCollapsed`
- 검증 — 컴파일

> **선언 순서가 화면 순서다.** 화면이 다시 정렬하면 정렬 지점이 둘로 갈라진다.

### 2. 분류 계약 테스트 — 🔴 RED (5분)

- 파일 — `CaptureTaskTests/DueGroupingTests.swift` (새 파일)
- 고정 `now` = 2026-08-01 14:00
- 어제 / 오늘 / 7일 뒤 / 8일 뒤 / 날짜 없음 / 완료
- **시간 명시 + 그 시각 지남 → overdue**
- **종일 + 오늘 자정 → today** (저녁에도)
- 검증 — 전부 실패하는 것을 눈으로 본다

### 3. `DueGrouping.bucket` (4분)

- `now` 를 인자로 받는다. 안에서 `.now` 를 읽으면 테스트가 오늘 날짜에 흔들린다
- 검증 — 2번이 초록

### 4. 순서 계약 테스트 — 🔴 RED (4분)

- 묶음 순서 / 지난 마감 오래된 것부터 / 마감 이른 것부터 / 날짜 없음은 최근부터
- 검증 — 실패 확인

### 5. `DueGrouping.groups` · `.sorted` (5분)

- 빈 묶음은 넣지 않는다
- 검증 — 4번이 초록

### 6. `WalletStackLayout` 순수 함수 (4분)

- 파일 — `CaptureTask/Models/WalletStackLayout.swift` (새 파일)
- `offset(forCardAt:expandedIndex:)` · `height(...)` · `totalHeight(...)`
- 검증 — 7번

### 7. 배치 계약 테스트 (5분)

- 파일 — `CaptureTaskTests/WalletStackLayoutTests.swift` (새 파일)
- `peekHeight < collapsedHeight` (겹침의 정의)
- 펼친 카드 아래가 통째로 밀린다
- 펼친 카드 위는 안 움직인다
- 펼친 카드와 다음 카드가 겹치지 않는다
- **마지막 카드가 잘리지 않는다**
- 검증 — 7건 초록

> 배치를 순수 함수로 뺀 이유. "겹쳐 보인다" / "아래가 잘린다"는 눈으로만 잡으면 매번 놓친다.

### 8. `TaskCard` 뷰 (5분)

- 파일 — `CaptureTask/Views/TaskCard.swift` (새 파일)
- 접힘: 제목 1줄 + 마감 + 배지 — **위쪽 64pt 안에** 다 들어가야 한다
- 펼침: 구분선 + 메모 4줄 + 태그 + 삭제
- 접근성 — 카드 하나가 한 요소. `"제목, 마감, 묶음"`
- 검증 — 시뮬레이터

### 9. `DueStackView` (5분)

- 파일 — `CaptureTask/Views/DueStackView.swift` (새 파일)
- `ZStack(alignment: .top)` + `offset(y:)` + `zIndex` — 아래 카드가 위 카드를 덮어야 지갑이 된다
- `@State expandedTaskID` 하나 (화면 전체에서 하나만 펼쳐진다)
- 검증 — 시뮬레이터

### 10. 묶음 접기 (3분)

- `@State collapsedBuckets` — `startsCollapsed` 로 초기화
- 접을 때 안의 펼친 카드도 함께 접는다
- 검증 — 시뮬레이터

### 11. 알림줄 (3분)

- 확인할 할 일 N개 / 담기 불가 / 알림 꺼짐
- 검증 — 시뮬레이터
