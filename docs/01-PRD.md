# PRD

## 제품 원칙

1. 캡처를 잃지 않는 것이 자동화 속도보다 중요하다.
2. 틀린 자동 저장보다 한 번의 명확한 확인이 낫다.
3. 앱 할 일이 원본이고 캘린더는 선택적 사본이다.
4. 로컬에서 충분한 처리는 로컬에서 한다.
5. AI 공급자는 교체 가능해야 한다.

## MVP 범위

### 포함

- 단일 이미지 공유
- 한국어/영어 OCR
- 할 일 제목, 상세, 날짜, 시간, 신뢰도 제안
- 확인/수정
- 앱 내 할 일 목록, 완료, 삭제
- Apple 캘린더 추가
- 권한 거절 및 오프라인 실패 복구

### 제외

- 메모 앱 직접 쓰기
- 여러 캘린더 양방향 동기화
- 반복 일정
- 연락처/메일/메시지 자동 실행
- 사용자 확인 없는 완전 자동 저장

## 성공 기준

- 캡처 유실률 0%
- 날짜가 없는 캡처의 캘린더 오저장 0%
- OCR 성공 캡처의 할 일 후보 생성률 95% 이상
- 크래시 없는 세션 99.5% 이상

## 주요 사용자 흐름

```text
스크린샷 → 공유 → CaptureTask에 담기 → 앱 열기
→ OCR/분석 → 확인 → 앱 할 일 저장
                     ↘ 선택 시 Apple 캘린더 저장
```
