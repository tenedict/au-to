# S-5.1 · 로컬 마감 알림

> 완료 2026-08-01

---

## 요구

> "그러고 할일 이거 푸쉬알림으로 막 보내줘야하고."

확정된 시점 (사용자 선택):

| 할 일 | 알림 |
| --- | --- |
| 시간 지정 | 마감 **1시간 전** |
| 종일 | 마감 당일 **09:00** |
| 공통 | 마감 **하루 전 20:00** |

---

## 되물어서 갈린 결정

| 질문 | 결정 | 왜 |
| --- | --- | --- |
| 서버 푸시인가 로컬 알림인가? | **로컬** | 할 일은 기기에만 있다. 서버 푸시를 쓰려면 서버가 사용자의 할 일과 마감을 알아야 하고, 그 순간 이 앱의 프라이버시 성질이 통째로 바뀐다 |
| 마감 시각이 이미 지났으면? | **걸지 않는다** | iOS 가 조용히 버리거나 즉시 울린다. 둘 다 고장으로 읽힌다 |
| 완료하면? | **전부 취소** | 끝낸 일로 울리면 사용자는 알림 전체를 꺼 버린다 |
| 완료를 되돌리면? | **다시 예약** | |
| 시각 계산을 서비스 안에 둘까? | **아니오, 순수 함수** | 서비스 안에 두면 검증하려고 실제 알림을 예약해야 한다. 그러면 아무도 검증하지 않고, 사용자는 안 오는 알림을 기다린다 |
| 사용자에게 뭐라고 말할까? | **실제 예약 시각을 그대로** | "알림을 보내드려요"는 지켜졌는지 확인할 방법이 없는 약속이다 |

## 태스크

### 1. `ReminderKind` · `ReminderPlan` (2분)

- 파일 — `CaptureTask/Models/ReminderSchedule.swift` (새 파일)
- `dayBeforeEvening` / `morningOfDueDay` / `oneHourBefore`
- 검증 — 컴파일

> `rawValue` 가 알림 식별자에 들어간다. 바꾸면 **이미 예약된 알림을 취소하지 못한다.**

### 2. 시각 계약 테스트 — 🔴 RED (6분)

- 파일 — `CaptureTaskTests/ReminderScheduleTests.swift` (새 파일)
- `Asia/Seoul` 고정 캘린더, 고정 `now`
- 시간 지정 → `[하루 전 20:00, 1시간 전]` 정확한 값으로
- 종일 → `[하루 전 20:00, 당일 09:00]`
- 종일에 1시간 전이 **없는지**
- 지난 시각 전부 제외 / 일부만 남는 경우
- 마감 없음 · 완료 · 알림 끔 → 빈 배열
- **`remindersEnabled == nil` 이면 켠 것으로** (구버전 파일)
- 검증 — 실패 확인

### 3. `ReminderSchedule.plans` (5분)

- `now` 를 인자로 받는다
- `fireAt > now` 만 남기고 이른 순 정렬
- 검증 — 2번이 초록

### 4. 식별자 (2분)

- `"<taskID>#<kind.rawValue>"`
- `allIdentifiers(taskID:)` — 재예약 시 이 전부를 지운다
- 검증 — `testIdentifiersAreUniquePerKind`

### 5. `AssistantTask.remindersEnabled` — **옵셔널** (3분)

- 파일 — `CaptureTask/Models/AssistantTask.swift`
- 읽기는 `wantsReminders` (`?? true`)
- 구버전 JSON 디코딩 테스트를 **함께** 쓴다
- 검증 — `testDecodesTaskSavedBeforeRemindersFieldExisted`

> 기본값이 있어도 옵셔널이 아니면 예전 파일이 `keyNotFound` 로 안 열리고,
> 사용자는 할 일을 **통째로** 잃는다.

### 6. `TaskReminderScheduling` 프로토콜 + 구현 (5분)

- 파일 — `CaptureTask/Services/NotificationService.swift` (새 파일)
- `LocalNotificationService` — `UNCalendarNotificationTrigger`
- `RecordingReminderScheduler` — 테스트용, 실제로 걸지 않고 기록만
- **재예약은 항상 먼저 전부 지운다**
- 검증 — 7번

### 7. `TaskStore` 연결 + 테스트 (5분)

- 저장 → 권한 요청(마감 있을 때만) → 재예약
