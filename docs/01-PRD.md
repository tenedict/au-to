## 1. 제품 원칙

1. **캡처를 잃지 않는 것이 자동화 속도보다 중요하다.**
   분석·캘린더·알림이 전부 실패해도 담아 둔 스크린샷은 남는다.
2. **틀린 자동 저장보다 한 번의 명확한 확인이 낫다.**
   확인 화면을 지나지 않는 저장 경로는 없다.
3. **앱 할 일이 원장이고 나머지는 시점이다.**
   캘린더도, 캘린더 탭도, 알림도 원장이 아니다.
4. **로컬에서 충분한 처리는 로컬에서 한다.**
   OCR 은 온디바이스, 알림은 로컬 알림. 나가는 것은 OCR 텍스트뿐이다.
5. **AI 공급자는 교체 가능해야 한다.**
   고르는 지점이 한 곳이어야 옮길 수 있다.
6. **실패는 조용하면 안 된다.**
   자동 대체(fallback)도, 삼킨 오류도, 없다고 통과시키는 검사도 만들지 않는다.

## 2. 확정 결정

| # | 결정 | 근거 |
| --- | --- | --- |
| 1 | 앱 안에 독립적인 할 일 목록을 둔다 | 원장의 소유권을 앱이 갖는다 |
| 2 | 캘린더는 선택적 외부 출력이다 | 저장 실패가 할 일을 되돌리지 않는다 (ADR-7) |
| 3 | 앱 안 캘린더는 **읽기 전용 월 뷰** 하나 | Apple 캘린더가 이미 캘린더다. 두 원장을 만들지 않는다 |
| 4 | 알림은 **로컬 알림** | 서버 푸시는 서버가 할 일을 알아야 한다 (ADR-8) |
| 5 | 알림 시점 — 시간 지정 1시간 전 · 종일 당일 09:00 · 공통 하루 전 20:00 | 예약·회의는 이동이 필요하고, 종일 일은 하루 시작에 한 번 |
| 6 | OCR 은 온디바이스 Vision 이 기본 | 원본 이미지가 기기를 떠나지 않는다 |
| 7 | 문맥 해석은 초기 OpenAI, 이후 온디바이스로 교체 가능하게 | 기준선 없이 온디바이스로 가면 품질을 비교할 수 없다 (ADR-10) |
| 8 | OpenAI 호출은 앱이 아닌 백엔드가 한다 | 앱 번들의 문자열은 누구나 꺼낸다 (ADR-5) |
| 9 | 홈은 마감 급한 순 **지갑 스타일 스택** | 목록은 "다음에 뭘 하지"에 답하지 못한다 |
| 10 | Share Extension 은 담기만 한다 | 무거운 작업을 넣으면 시스템이 죽인다 (ADR-2) |

## 3. MVP 범위

### 포함 ✅

| | 상태 |

| 단일 이미지 공유 → App Group 상자 | 🟡 실기기 미확인 |

| 확인 화면 (수정·나중에·버리기) | ✅ |
| 확인하지 않은 초안의 영속화 | ✅ |

| 완료·해제·삭제 | ✅ |

### 제외 ❌

| | 왜 |
| --- | --- |
| 메모 앱 직접 쓰기 | 원장이 또 늘어난다 |
| 캘린더 양방향 동기화 | ADR-7 |
| 반복 일정 | 마감 하나를 먼저 제대로 |
| 연락처·메일·메시지 자동 실행 | 확인 없는 부작용 |
| 사용자 확인 없는 완전 자동 저장 | 원칙 2 |
| 서버 푸시 알림 | 결정 4 |
| 검색·필터·중복 감지 | 할 일이 적은 초기에는 스택으로 충분 |

## 4. 성공 기준

| 기준 | 목표 | 지금 |
| --- | --- | --- |
| 캡처 유실률 | 0% | ✅ 확인 전 삭제 금지 |
| 날짜 없는 캡처의 캘린더 오저장 | 0% | ✅ 확인 화면 필수 |
| OCR 성공 캡처의 할 일 후보 생성률 | 95% 이상 | ⬜ 평가셋 없음 |
| 공유 → 확인 완료 중앙값 | 15초 이내 | ⬜ 미측정 |
| 제목 무수정 저장률 | 80% 이상 | ⬜ 미측정 |
| 크래시 없는 세션 | 99.5% 이상 | ⬜ 측정 수단 없음 |

**여섯 중 넷이 아직 측정되지 않는다.** 측정은 S-2.3(평가셋)과 실기기 사용에서 시작한다.

## 5. 주요 흐름

```
스크린샷 → 공유 → 담기 → 앱 열기
  → OCR → 분석 → 확인
      ├─→ 앱 할 일 저장        (항상)
      ├─→ 마감 알림 예약        (마감이 있고 켜 뒀으면)
      └─→ Apple 캘린더 저장     (켜 뒀으면 · 실패해도 위는 남는다)

앱 열기 → 지갑 스택 (지난 마감이 맨 위)
       → 카드 탭 → 펼침 → 완료 / 삭제
```

자세한 것은 [07-유저플로우.md](07-유저플로우.md).
