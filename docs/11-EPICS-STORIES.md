### S-1.3 · 실기기 공유 E2E — 다음 스토리

**수용 기준**
1. 실제 iPhone 사진 앱 공유 시트에 "CaptureTask에 담기"가 보인다
2. 공유 후 이미지와 메타데이터가 App Group 상자에 남는다
3. 앱을 열면 OCR 후 확인 화면이 **한 번만** 보인다
4. 앱 강제 종료·오프라인에서도 캡처가 사라지지 않는다
5. 확인을 미룬 뒤 앱을 껐다 켜도 같은 캡처를 다시 분석하지 않는다

**막고 있는 것** — 개발자 계정에 App Group 등록, Bundle ID 확정 (D-1)

### S-2.4 · OpenAI 백엔드 어댑터 (완료)

**수용 기준**
1. ✅ iOS 앱이나 Share Extension 에 OpenAI API 키가 포함되지 않는다
2. ✅ `POST /v1/analyze-capture` 는 OCR 원문·locale·timezone·현재 시각을 받는다
3. ✅ 서버는 Responses API 와 strict JSON Schema 로 초안을 반환한다
4. ✅ `store: false`, 모델군에 맞는 파라미터를 쓴다
5. ✅ 빈 원문·과대 요청·OpenAI 오류·타임아웃·잘못된 응답을 구분해 반환한다
6. ✅ API 키가 없거나 자리표시자인 서버는 시작 즉시 실패하고 원인을 설명한다
7. ✅ 단위 테스트가 실제 OpenAI 호출 없이 요청 계약과 응답 파서를 검증한다
