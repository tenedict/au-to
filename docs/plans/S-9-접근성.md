# S-9 · 접근성 마감 품질 (S-9.1 ~ S-9.4)

> 완료 2026-08-01 · R2 게이트의 접근성 차단 3건을 없앤다.

---

## 왜 이것을 다음으로 골랐나

남아 있던 할 일 중 사람의 결정(D-1)·실기기·API 키가 필요 없는 유일한 묶음이고,
**R2 릴리스 게이트를 막고 있었다.** 그리고 S-9.1 은 지갑 스택을 만들 때 진 빚이다 —
겹침 계산을 순수 함수로 유지하려고 카드 높이를 고정값으로 뒀고, 그 대가가 여기서 왔다.

---

## 되물어서 갈린 결정

| 질문 | 결정 | 왜 |
| --- | --- | --- |
| 큰 글자에서 겹침을 유지할까? | **접근성 크기부터는 포기한다** | 배율만 키우면 마감 날짜가 두 줄로 넘쳐 다음 카드가 덮는다. 실제로 그렇게 됐다 |
| 어디서 갈라야 하나? | `dynamicTypeSize.isAccessibilitySize` | 시스템이 정한 경계다. 우리가 임의로 정하면 다음 iOS 에서 어긋난다 |
| 배율 계산을 어디 둘까? | **모델의 `scaled(by:)`** | 환경을 모델이 읽으면 테스트가 기기 설정에 흔들린다 |
| 대비 높이기에서 무엇이 바뀌나? | **그림자 → 테두리** | 겹침을 읽히게 하는 단서가 그림자뿐인데, 대비를 높이면 그림자가 안 보인다 |
| 알림을 누르면 어디로? | **그 할 일을 펼친다** | 목록 맨 위에서 다시 찾게 하면 알림의 목적이 사라진다 |
| 앱을 보고 있을 때 알림은? | **보여준다** | 기본 동작은 조용히 삼키는 것이라 앱을 켜 둔 사용자가 마감을 놓친다 |

## 태스크

### S-9.1 · 접근성 글자 크기 (총 20분)

**1. `WalletStackLayout.scaled(by:)` (3분)**
- 세 값을 **함께** 곱한다. 하나만 키우면 겹침이 사라지거나 카드가 서로를 덮는다
- 1 미만 배율은 1로 막는다 — 0이 들어오면 카드가 사라진다
- 검증 — 2번

**2. 배율 계약 테스트 — 🔴 RED (5분)**
- 배율 1.0~3.5 전 구간에서 `peek < collapsed`
- 펼친 카드와 다음 카드가 겹치지 않는다
- 전체 높이가 배율만큼 커진다 (마지막 카드가 안 잘린다)
- 1 미만 배율은 기본 레이아웃과 같다
- 검증 — 4건 초록

**3. `DueStackView` 에 `@ScaledMetric` 연결 (2분)**
- 검증 — 시뮬레이터 `content_size accessibility-extra-extra-extra-large`

**4. 눈으로 확인 → 실패를 본다 (2분)**
- 배율만으로는 부족했다. "2026년 7월 30일"이 두 줄로 넘쳐 다음 카드가 덮었다
- **이 단계가 이 작업의 핵심이다.** 테스트는 초록인데 화면은 여전히 잘려 있었다

**5. 접근성 크기에서 목록으로 전환 (5분)**
- `usesWalletStack = !dynamicTypeSize.isAccessibilitySize`
- `plainList(for:)` — 겹침 없음, 높이는 내용에 맡김
- 검증 — 시뮬레이터

**6. `TaskCard` 에 `isStacked` 전달 (3분)**
- 겹칠 때만 제목 1줄 제한. 겹치지 않으면 줄 수를 푼다
- 마감·배지를 겹칠 때는 가로로, 아닐 때는 세로로
- 검증 — 시뮬레이터

### S-9.2 · 모션 줄이기 (4분)

- `@Environment(\.accessibilityReduceMotion)` → `expandAnimation` · `collapseAnimation` 이 `nil`
- 펼친 내용의 전이도 `.opacity` 만 (이동 없음)
- 검증 — 시뮬레이터 설정

### S-9.3 · 대비 높이기 (4분)

- `@Environment(\.colorSchemeContrast)` → 그림자 0, 테두리 1pt
- 검증 — `xcrun simctl ui booted increase_contrast enabled/disabled` 두 장 비교

### S-9.4 · 알림 탭 라우팅 (8분)

- `ReminderTapRouter` — `UNUserNotificationCenterDelegate`
- `didReceive` → `requestedTaskID`
- `willPresent` → 앱을 보고 있어도 배너를 띄운다
- `WhenlyApp.onAppear` 에서 델리게이트 설치 (첫 화면 뒤에 붙이면 첫 실행을 놓친다)
- `RootView` 가 받아 할 일 탭으로 옮기고 그 카드를 펼친다
- `expandedTaskID` 를 `DueStackView` 에서 `RootView` 로 끌어올린다

## 남긴 것

**G-5 · 펼친 카드 높이 248pt 고정은 그대로 둔다.**
가변 높이로 바꾸면 겹침 계산이 뷰 렌더 결과에 의존하게 되고, 그 순간
`WalletStackLayoutTests` 가 검증하는 것이 실제 화면과 달라진다.
접근성 크기에서는 이미 목록으로 바뀌므로 이 제약이 걸리는 사용자는 없다.
